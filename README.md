# Barangay Community Connect

A simple community portal that connects residents with their barangay for announcements, public services, emergency hotlines, and volunteer updates.

## Features
- **Barangay Announcements:** Advisories, health missions, and community schedules.
- **Emergency Hotlines:** Quick-access contact cards with an instant emergency reminder alert.
- **Volunteer Sign-Up:** Interactive community clean-up drive registration with live volunteer counter.

## Technologies Used
- **HTML5** (`index.html`) — Semantic page structure
- **CSS3** (`style.css`) — Responsive styling with *Ink Free* / *Times New Roman* typography and animations
- **JavaScript** (`Javascript.js`) — Interactive emergency alert and volunteer sign-up counter
